# heart-disease-prediction-ml

# Heart Disease Prediction Using Machine Learning Models

## Project Overview
This project investigates the prediction of heart disease using supervised machine learning algorithms and clinical patient data.

## Dataset
IEEE DataPort Comprehensive Heart Disease Dataset

- Original records: 1,190
- Records after duplicate removal: 918
- Input features: 11
- Target: Presence or absence of heart disease

## Machine Learning Models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest
5. Tuned Random Forest (GridSearchCV)

## Methodology
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Automated feature selection using SelectKBest
- Feature standardization
- Model training and evaluation
- Performance comparison

## Model Performance

| Model | Accuracy |
|---|---|
| Logistic Regression | 86.96% |
| KNN | 86.41% |
| Decision Tree | 79.35% |
| Random Forest | 86.41% |
| Tuned Random Forest | 86.41% |

## Key Findings
Logistic Regression achieved the highest accuracy of 86.96%, with 91.18% recall and an F1-score of 88.57%.
